A few useful details

Before you get started.

What is a media server?

It is an application that organizes and serves media stored on a computer. SlopTank runs on that computer, while its web player lets you browse and watch the library from a browser.

Does it come with anything to watch?

No. You supply your own movies and shows. The artwork on this page is an illustration, not an included catalogue.

How is SlopTank related to Jellyfin?

SlopTank is a fork of Jellyfin. It builds on Jellyfin's media-server and web-client code, with changes to the browsing and playback experience. Jellyfin is a separate project; this is not its official website.

Where can I find source and licence information?

The server repository and web-client repository include source, licence files, and project notices. Release-specific source and notices will accompany the public download.
